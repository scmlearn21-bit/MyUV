# MyUV ☀️

A cross-platform React Native (Expo) app that tracks real-time local UV index data, provides SPF protection guidance based on skin type, and sets local sunscreen reapplication reminders.

## Run on Your iPhone (No Mac Required)
1. Install **Expo Go** from the iOS App Store on your iPhone.
2. Open this project in [snack.expo.dev](https://snack.expo.dev) or run `npx expo start` on Windows/Chromebook.
3. Scan the QR code with your iPhone camera to launch **MyUV**.
